# dy-shot-proof · 证据贴纸

> 写法照 mg-styles-15 `template.md`（MIT）的四段。共同语法见 `../STYLE.md`。

## 用途

口播指着一张**真实截图**（AI 的回答、App 页面、文档）讲"这里写了什么"：镜头依次推到 1–4 处，每处高亮 + 引线标签，最后拉回全景、右边列出各处。观众看到的是实测里真实发生的画面，不是画出来的界面。

适合：「开头一句本周重点」「它把 1800 元写对了」「额度用尽了」。不适合：录屏里的操作过程（用 dy-shot-rec）、AI 答错要盖章（用 dy-shot-stamp）。

## 节拍（按 cues 的拍）

| 时刻 | 发生什么 |
|---|---|
| 0 s | 首帧：标题（可选，72px 900）+ 截图贴纸全貌（白描边、胶带、点阵画布），一屏看全 |
| 第 i 拍前 0.25–0.4 s | 镜头 `power2.inOut` 推到第 i 处（0.5–0.85 s；两拍挨得近时走得快），这一处落在画面 (540, 600) |
| 第 i 拍附近 | 高亮框从左往右展开（0.35 s）→ 引线画出（0.3 s）→ 标签 `back.out(1.4)` 弹出（落点音效 pop） |
| 下一拍镜头开走时 | 标签、引线淡出（0.2 s，至少停 0.6 s） |
| 最后 2.2 s | 镜头拉回 0.86 倍、截图让到左边；每处出现序号圆点；右边列表逐条出现 `power3.out`，停住 |

## 标志特征和关键技法（评审按这些看）

- 截图是贴纸：`HF.sticker`（10px 白描边 + 硬边 + 远近两层投影）+ 一条荧光黄胶带压在顶边
- 画布 2160×3840、点阵 36px 间距，镜头只动画布层（`HF.camera`），截图本身不动
- 推近倍数 = max(字在屏幕上 ≥46px, 区域宽约 760px)，上限 5 倍；推近点标 `data-vd-zoom`，vd qa 查它在内容区里、字 ≥37px
- 取景窗：画布只在 y 290–1160 里显示（上面是栏目标签，下面是字幕带），左右出血
- 高亮框边宽、圆角按推近倍数反算，推近后屏幕上始终是 5px 边、8px 圆角
- 标签：荧光黄底 54px 900，黑色 4px 描边 + 10px 硬投影；引线 4px + 9px 圆点；标签在高亮框下方左右交替
- 颜色只用主题变量；荧光黄 = 重点，不出现红色

## 变量

| 变量 | 说明 | 上限 |
|---|---|---|
| `src` | 截图路径（相对项目根目录，必须是实测截图） | |
| `ratio` | 截图高/宽（1080×1920 填 1.778，1080×2400 填 2.222） | |
| `title` | 上方标题，可空 | 12 字 |
| `labels` | 标注文字，`\|` 分隔，1–4 条 | 每条 10 字 |
| `boxes` | 标注区域，`\|` 分隔，每条 `x,y,w,h`（截图百分比）；区域宽 × 推近倍数超过 900px 时 vd qa 会报出内容区，框窄一点（框关键词，不框整行） | |
| `textPx` | 截图里正文字的像素高（原尺寸，手机截图约 40） | |
| `cues` | 每条标注一拍（vd 从 `@词` 换算） | |
| `enter` / `exit` | 平移转场（vd 自动填） | |

## 三组内容（tests/cases/dy-shot-proof.json）

- **short**（5 秒）：飞书妙记「当前额度已用尽」通知，1 处，无标题
- **typical**（9 秒）：第 1 期 DeepSeek 写的周报，3 处（本周重点 / 首日 1800 元 / 问题要协调），有标题
- **long**（15 秒）：第 2 期妙记会议纪要长截图（1080×2400），4 处，标题 11 字

素材在 `tests/media/shots/`（第 1、2 期的实测截图，数据是造的；用户 2026-10-20 同意公开）。单组渲染：`node tests/render-shot.mjs dy-shot-proof <组> <秒> <out.mp4>`。
